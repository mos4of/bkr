## ✨ Особливості

### 🎨 Сучасний інтерфейс
- **CustomTkinter GUI** з темною темою (Dark Mode)
- **Анімації** через threading + after() в tkinter
- **Splash screen** при запуску (2 секунди)
- **Кастомні прогрес-бари** з градієнтом
- **Термінальний стиль** логів (Consolas, зелений текст)

### 🔧 Три режими роботи

#### РЕЖИМ 1: Файл (вже реалізовано)
- Знищити один конкретний файл обраним методом
- Показує прогрес знищення
- Верифікація після завершення

#### РЕЖИМ 2: Папка (НОВЕ)
- Рекурсивно пройти по всіх файлах у папці включно з підпапками
- Знищити кожен файл обраним методом (zeros / DoD / Gutmann)
- Показує прогрес: "Файл 12 з 47: report.docx"
- Після знищення всіх файлів — видаляє порожні папки
- У лог записує кількість знищених файлів і загальний розмір

#### РЕЖИМ 3: Вільний простір диску (НОВЕ)
- Користувач обирає диск (C:\, D:\ тощо)
- Програма визначає скільки вільного місця на диску
- Заповнює вільний простір тимчасовими файлами нулями або random
- Показує прогрес заповнення у GB: "Заповнено 12.3 GB з 47.8 GB"
- Потім видаляє ці тимчасові файли
- Це знищує залишки раніше видалених даних у вільному просторі

### 📊 Live статистика
- ✅ Поточний прохід (Pass X/Y)
- ✅ Швидкість (MB/s)
- ✅ Залишок часу (ETA)
- ✅ Відсоток завершення (0-100%)
- ✅ Для папки: "Файл X з Y"
- ✅ Для диску: "Заповнено X.X GB з Y.Y GB"

### 🛡️ Безпека
- ⚠️ **Підтвердження** перед знищенням (модальний діалог)
- ⚠️ **Перевірка існування** шляху
- ✅ **Верифікація** після знищення
- ✅ **Логування** у файл (дата, метод, результат, час)
- ✅ **Очищення слідів Windows** (опціонально)

### 🎯 Додатково
- 🧪 **Тестовий режим** - безпечна демонстрація з тестовим файлом (10 МБ)
- 📁 **Drag & Drop** - перетягніть файл у поле цілі
- 📋 **Експорт звіту** - збереження результатів (TXT)
- 💾 **Системний трей** - іконка при згортанні (опціонально)
- 🧹 **Очищення артефактів Windows**:
  - Очищення Кошика (Recycle Bin)
  - Очищення Prefetch
  - Очищення Recent files
  - Очищення Thumbnail cache
  - Видалення тіньових копій VSS (потребує прав адміністратора)

## 🔧 Стандарти безпеки

### DoD 5220.22-M
Стандарт Міністерства оборони США для очищення та знищення інформації на магнітних носіях.

**Процедура (3 проходи):**
1. Записати 0x00 по всьому носію
2. Записати 0xFF по всьому носію
3. Записати випадкові байти (os.urandom)

### Схема Гутмана (Gutmann)
Метод безпечного видалення даних, розроблений Пітером Гутманом. Оригінальний метод передбачає 35 проходів, але для сучасних носіїв достатньо спрощеної версії з 7 проходами.

**Процедура (7 проходів):**
1. 0x00
2. 0xFF
3. Random
4. 0xAA
5. 0x55
6. Random
7. 0x00

## 🎮 Використання

### Основний режим

1. **Виберіть режим** - натисніть на одну з радіокнопок (Файл / Папка / Диск)
2. **Виберіть метод** - натисніть на одну з радіокнопок (Zeros, DoD, Gutmann, Verify)
3. **Виберіть ціль** - натисніть 📁 або перетягніть файл/папку у поле
   - Для диску: оберіть диск з випадаючого списку
4. **Запустіть** - натисніть 🗑️ START WIPE
5. **Підтвердіть** - натисніть "Так" у діалозі підтвердження
6. **Спостерігайте** - за прогресом у реальному часі

### Тестовий режим

1. Натисніть **🧪 TEST MODE**
2. Програма створить тестовий файл (10 МБ) з псевдо-даними
3. Виберіть метод знищення
4. Запустіть знищення
5. Перегляньте результати верифікації

### Очищення слідів Windows

1. Натисніть **🧹 ОЧИСТИТИ СЛІДИ**
2. Підтвердіть операцію
3. Програма очистить:
   - Кошик (Recycle Bin)
   - Prefetch файли
   - Recent files
   - Thumbnail cache
   - Тіньові копії VSS (якщо є права адміністратора)
