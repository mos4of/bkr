# Secure Wipe Tool v1.0

Програма безпечного знищення даних на носіях для демонстрації БКР на тему «Безпечне виведення з експлуатації технічних засобів».

## Опис

Інструмент реалізує різні методи безпечного видалення даних з можливістю верифікації результату. Програма має тестовий режим для безпечної демонстрації без ризику втрати реальних даних.

## Функціонал

### Методи знищення даних:

1. **Zeros (1 pass)** - перезаписування нулями
2. **DoD 5220.22-M (3 passes)** - стандарт Міністерства оборони США
   - Прохід 1: 0x00
   - Прохід 2: 0xFF
   - Прохід 3: випадкові байти
3. **Gutmann simplified (7 passes)** - спрощена схема Гутмана
   - Чергування: 0x00, 0xFF, random, 0xAA, 0x55, random, 0x00
4. **Verify only** - перевірка чистоти носія

### Додаткові можливості:

- Прогрес-бар (використовує tqdm або власну реалізацію)
- Логування операцій у файл
- Тестовий режим з безпечною демонстрацією
- Підтвердження перед знищенням даних
- Графічний інтерфейс (GUI) на tkinter
- Завантаження коду з GitHub

## Вимоги

- Python 3.x
- tkinter (зазвичай входить до стандартної поставки Python)
- tqdm (для прогрес-бару)
- ОС: Windows/Linux (крос-платформна)

## Встановлення

1. Клонуйте репозиторій або завантажте файли:
   ```bash
   git clone https://github.com/mos4of/bkr.git
   ```
2. Встановіть залежність:
   ```bash
   pip install tqdm
   ```

## Використання

### Графічний інтерфейс (GUI):

```bash
python secure_wipe_gui.py
```

GUI версія включає:
- Вибір методу знищення через радіокнопки
- Вибір файлу через діалог
- Кнопку для створення тестового файлу
- Кнопку для завантаження коду з GitHub
- Консоль виводу в реальному часі
- Прогрес-бар під час операції

### Основний режим (CLI):

```bash
python secure_wipe.py
```

Програма запустить інтерактивне меню:
1. Оберіть метод знищення (1-5)
2. Вкажіть шлях до файлу
3. Підтвердіть операцію

### Тестовий режим (рекомендовано для демонстрації):

Оберіть пункт [5] в меню - "Test mode (safe demo)"

Цей режим:
- Автоматично створює тестовий файл (10 МБ) з псевдо-даними
- Виконує обраний метод знищення
- Проводить верифікацію результату
- Зберігає лог операції

## Структура коду

### CLI версія (secure_wipe.py):
- `wipe_zeros(target_path, block_size)` - метод 1
- `wipe_dod(target_path, block_size)` - метод 2
- `wipe_gutmann(target_path, block_size)` - метод 3
- `verify_wipe(target_path, block_size)` - верифікація
- `save_log(method, target, result, duration)` - логування
- `create_test_file(filename, size_mb)` - створення тестового файлу
- `test_mode()` - тестовий режим
- `main()` - головна функція

### GUI версія (secure_wipe_gui.py):
- `SecureWipeGUI` - головний клас інтерфейсу
- `clone_from_github()` - завантаження з репозиторію
- `download_zip()` - альтернативне завантаження через ZIP
- `start_wipe()` - запуск знищення в окремому потоці
- `RedirectText` - перенаправлення виводу в текстовий віджет

## Логування

Всі операції логуються у папку `logs/`:
- Дата та час операції
- Використаний метод
- Шлях до цілі
- Результат (SUCCESS/FAILED)
- Час виконання

## Безпека

⚠️ **УВАГА**: Програма виконує безповоротне знищення даних!

- Перед знищенням завжди виводиться попередження
- Потрібне підтвердження користувача (y/n)
- Перевіряється існування вказаного шляху
- Рекомендується використовувати тестовий режим для ознайомлення
- У GUI версії також є підтвердження через діалогове вікно

## Завантаження з GitHub через GUI

У графічному інтерфейсі є кнопка "📥 Завантажити з GitHub", яка:
1. Спробує використати `git clone` (якщо git встановлено)
2. Якщо git не знайдено, завантажить ZIP-архів з репозиторію
3. Автоматично розпакує архів у поточну папку
